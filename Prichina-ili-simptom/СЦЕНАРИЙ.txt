ПРИЧИНА ИЛИ СИМПТОМ? — СЦЕНАРИЙ 25.11.2026

Запуск: START-GAME.cmd. Интернет и установка программ не нужны.

Основной маршрут:
1. Производство: ПР-4 → ПР-3 → ПР-2.
2. Качество: КА-3 → КА-2 → КА-1.
3. Персонал: ПЕ-3 → ПЕ-2 → ПЕ-1, затем итоги игры.

Первый активный кейс — тренировка. По умолчанию на обсуждение
20 минут. Дайте каждому высказаться, разберите ход анализа и вопросы.
Оценки тренировки видны как обратная связь, но не входят в общий рейтинг.
Обычное обсуждение — 10 минут. Доклад каждой команды — 3 минуты.
Всё меняется в «Подготовка» → «Время и очки»; тренировку можно отключить.

«Поставки» находятся в резерве. В «Подготовка» → «План игры»
нажмите кнопку сектора для скрытия или восстановления.
Галочка «В игре» в строке делает то же с отдельным кейсом.
Если скрыт весь сектор, для возврата его кейсов сначала включите сектор.
Резерв не показывается на поле, не участвует в обычном ходе игры,
расчёте длительности и рейтинге. Карточки и оценки не удаляются.
Чтобы использовать резерв для спорной ситуации, включите нужный сектор
или кейс и откройте его в ленте вкладки «Игра».
Идущий кейс нельзя скрыть до завершения; хотя бы один должен быть видимым.
Все карточки, включая не включённые в план, остаются во вкладке «Карточки».

Кнопка «Восстановить сценарий» возвращает исходный порядок и резерв.
После начала игры сначала используйте «Начать заново», если это нужно.
Восстановление сценария не меняет настроенные тайминги.

«Начать заново» сбрасывает ход игры, баллы, выданные факты и названия
команд (Команда 1, Команда 2…). Затем автоматически открывается мастер:
1. Команды и их названия.
2. Время обсуждения, тренировки и докладов.
3. Сектора, кейсы и автоловушки.
Состав, цвета команд, план и выбранные тайминги остаются основой для настройки.
В «Подготовке» эти параметры можно исправлять и во время игры.
Изменение текущего времени обсуждения/доклада сохраняет уже прошедшее время.
Кнопка повторного открытия мастера не сбрасывает прогресс.

Ловушки включены у всех новых кейсов по умолчанию. Галочку «Автоловушка»
можно убрать. На тренировке автоматический запуск отключён.
Кнопка «Проиграть ловушку» доступна в любом выбранном кейсе,
включая кейсы без галочки. Работающий таймер приостанавливается;
после закрытия ловушки он продолжается. Остановленный таймер не запускается.

«+ Факт» открывает окно только у ведущего. Выберите факт, прочитайте
вслух и нажмите «Выдал этот факт — записать». До подтверждения баллы
не списываются. «Другой факт» меняет предложенный текст.
«Журнал» у команды показывает фактически выданные факты. Выдачу можно
исправить (выбрать другой факт) без повторного списания либо отменить.
Записи сохраняются после перезапуска. На экран игроков текст не передаётся.

В игре и печатных материалах оставлено только круглое поле.
Копия версии до обновления управления — _backup-controls-2026-11-25.

Предыдущая сыгранная игра сохранена в data/game-before-scenario-2026-11-25.json.
Полная копия прежней версии — _backup-scenario-2026-11-25.
Для возврата старого хода игры остановите сервер и замените data/game.json
копией архивного JSON. Для возврата всей версии используйте полную копию.

Исходники обновлённой версии — папка source.
Для разработки: Node.js 24, npm ci, npm run dev.
Сборка: npm run build, затем node scripts/build-portable.mjs из source.
Сборка обновляет server и dist; текущие данные остаются на месте.
Обычный запуск игры использует встроенный node и не зависит от source.
